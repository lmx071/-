
# Accounting AI

个人记账与消费分析 AI 助手。

## 1. 项目介绍

本项目旨在通过大语言模型和 OCR 技术，
帮助用户进行自然语言记账、账单识别、
消费分类、消费统计和预算管理。

## 2. MVP 核心功能

- 自然语言记账
- 小票 / 支付截图 OCR 录入
- 消费自动分类
- 自然语言查账
- 预算设置与超支提醒

## 3. 项目技术栈

- LLM API
- OCR / Vision API
- SQLite
- 前端与后端技术栈：待团队确定

## 4. 项目目录

- frontend：前端代码
- backend：后端代码
- docs：项目文档
- data：示例数据
